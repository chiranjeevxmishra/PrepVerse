# PrepVerse

> **Your Personal Placement Preparation Network**

PrepVerse is a personalized, closed-loop placement preparation system designed for college students. Instead of fragmented resources across random platforms, PrepVerse provides a structured, data-driven workflow:

```
ASSESS ➔ IDENTIFY GAPS ➔ PLAN ➔ PRACTICE ➔ INTERVIEW ➔ RE-ASSESS ➔ IMPROVE
```

---

## 🛠️ Tech Stack

- **Frontend**: React (Vite), Tailwind CSS, React Router, Axios, Lucide Icons
- **Backend**: Node.js, Express.js (ES Modules), REST APIs, WebSockets (Socket.IO)
- **Database**: MongoDB & Mongoose
- **Security**: Helmet, CORS, Rate Limiting, JWT Authentication

---

## 📂 Project Structure
